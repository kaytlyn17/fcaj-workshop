**When:** 24 October 2026, 09:00–12:00 (Vietnam time)  
**Venue:** 26th floor, Bitexco Financial Tower, Ho Chi Minh City  
**Role:** Attendee

## From a Vietnamese voice call to the work of running an agent

In *Hear, Think, Speak*, Kiệt Trần from Revve AI demonstrated a Vietnamese-language screening call for a Cloud Engineer role. Listening to the two sides take turns made latency easier to understand than a number on a slide. Even a slightly longer pause after a question changes the rhythm of a conversation.

Three later sessions looked at the work behind demos like that one. Long Huỳnh of Styl Solution used AWS Resource Access Manager to explain how accounts share resources and how IAM policies and service control policies limit what a recipient can do. Thịnh Nguyễn, also from Styl Solution, showed why the pull request is a good time to review Terraform: the author still remembers the reason for the change. Xuân An from the AWS Student Builder Group at HCMUTE introduced Amazon Bedrock AgentCore and distinguished running an agent from managing what it remembers within and across sessions.

## Why Kiro Crew stood out to me

Khoa Kiều from ACB and Nghi Danh, an AWS Community Builder, discussed an agent designed to run continuously. After an example that turned job-market data into a chart, the Q&A moved to a less visible part of the system. As a conversation grows, someone has to decide what can be summarised, which details are worth retaining and when old memories should be cleared. Those choices affect both the cost of a run and the quality of the next answer.

In my next agent experiment, I would define which data it can read, which changes need human approval and how I will track token use over a longer run. I also plan to stay for the Q&A at future meetups. The audience’s questions brought out some of the most interesting constraints in this demo.
