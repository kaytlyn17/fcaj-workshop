## Objectives

- Get to know the mentors, fellow interns and rules of the First Cloud AI Journey (FCAJ) program.
- Understand cloud computing, the AWS global infrastructure and core services: IAM, VPC, EC2.
- Set up a secure AWS account and control costs from the very beginning.

## Achievements

- Understood cloud computing, the AWS global infrastructure and the Shared Responsibility Model.
- Created a secure AWS account (MFA, IAM user, Budgets) and learned how to control costs.
- Built a complete VPC (subnets, IGW, route tables, Security Groups, NACLs) and understood the difference between Security Groups and NACLs.
- Launched, connected to and managed EC2 instances; learned to use IAM Roles instead of Access Keys.
- Built the habit of cleaning up resources after every lab to avoid unexpected charges.
